# FinAcc Contabilidade

Site institucional simples e moderno para empresas de contabilidade.

## Objetivo

Apresentar a marca, os serviços oferecidos e os dados de contato de forma clara, profissional e responsiva.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura do projeto

- `index.html` — estrutura da página
- `style.css` — estilos visuais e responsividade
- `script.js` — interações simples do menu e botões
- `Assents/` — imagens e arquivos visuais
